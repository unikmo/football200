# Sponsor a Young Fan — Germany SEO & Conversion Map

## Search-positioning rule
Google language, audience pain language and product language are different layers. Use search language to capture demand, pain language to convert, and `Sponsor a Young Fan` as the named solution.

## Primary audience pages
| Route | Primary audience | Primary pain / intent | Primary framing |
|---|---|---|---|
| `/` | Football clubs | sponsors + young fans + low admin | Neue Sponsoren. Neue junge Fans. Wenig Aufwand. |
| `/verein.html` | Club decision makers | sponsoren finden / Sponsoring Verein | Sponsoren finden. Junge Fans gewinnen. Wenig Aufwand. |
| `/unternehmen.html` | Local companies | Sportsponsoring / local impact | Lokales Sportsponsoring, das ankommt. |

## Production SEO gate
The current demo is intentionally `noindex,nofollow`. Before production:
1. resolve production domain;
2. remove demo noindex;
3. add canonical URLs;
4. generate production sitemap.xml and robots.txt;
5. add validated structured data;
6. validate titles/H1s/internal links and page uniqueness;
7. run crawl + indexability QA;
8. run AI-searchability/entity QA.
